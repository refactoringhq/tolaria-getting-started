# Make It Yours

A few settings change how Tolaria looks and feels. Open Settings with `Cmd+,` or `Ctrl+,`.

### 🌗 Theme

Choose Light, Dark, or System. System follows your operating system's appearance as it changes. You can also switch the theme from the [[command-palette]].

### 🌍 Language

Tolaria's interface is available in more than 20 languages. By default it follows your system language when it's supported. Pick another one under Language in Settings. Missing translations fall back to English.

### 📏 Note width

Pick Normal for focused writing or Wide for tables, diagrams, and dense notes. Any single note can override the default from the editor toolbar.

### 🪟 Layout

Use `Cmd+1`, `Cmd+2`, and `Cmd+3` (`Ctrl` on Windows and Linux) to switch between the editor alone, the editor with the note list, and all panels.
