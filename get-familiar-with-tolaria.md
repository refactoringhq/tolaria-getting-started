# Get familiar with Tolaria

Use this checklist as a 15–20 minute tour of Tolaria. Every link opens a real file you can inspect, edit, and restore with Git.

`Cmd+click` on wikilinks to navigate 👇

- [ ] **Read the** Tolaria Principles — understand the core philosophy
- [ ] **Explore the** tolaria-sidebar — learn Inbox, All Notes, Archive, Favorites, Types, Folders
- [ ] **Browse the** tolaria-note-list — sorting, display properties, search within list
- [ ] **Try the** Editor and editor-playground — rich vs raw mode, callouts, blocks, code, highlights, whiteboards, PDF export, and collapsible sections
- [ ] **Open the** launch-plan-spreadsheet — values, formulas, wikilinks, formatting, and a cross-note property reference
- [ ] **Open the** project-dashboard — see a Markdown note render its own properties through a safe HTML block
- [ ] **Preview** sample-report.html — then toggle raw mode to inspect the standalone HTML source
- [ ] **Open the** Properties Panel — add a property, create a relationship
- [ ] **Try** tolaria-ai — choose an agent or direct model, understand permissions, and send a prompt with note context
- [ ] **Try the** command-palette — to do more from your keyboard
- [ ] **Check the** tolaria-bottom-bar and autogit — Git status, history, local commits, remotes, and optional checkpoints
- [ ] **Make it yours** in make-it-yours — theme, language, note width, and layout
- [ ] **Learn how to use** multiple-vaults — keep separate vaults open in one graph
- [ ] Mark this project as `status: done` when done
